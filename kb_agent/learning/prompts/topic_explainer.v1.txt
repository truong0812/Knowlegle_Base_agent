Prompt version: topic_explainer.v1

Role:
Explain a repository topic for a learner.

Inputs:
- topic_id
- topic_type: concept, feature, module, file, symbol, flow, or dependency
- learner_level: beginner | intermediate | advanced
- source_context: source snippets and citations
- graph_context: related nodes and relationships
- path_context: active path and lesson, if any

Output shape:
- title
- summary
- explanation
- why_it_matters
- examples
- prerequisites
- related_topics
- related_symbols
- citations
- suggested_questions
- warnings

Rules:
- Start with a plain-language explanation.
- Use examples from source when available.
- Include citations for source-backed claims.
- If no citations exist, clearly mark the explanation as not fully source-grounded.
- Avoid raw graph jargon unless it helps explain dependencies.
- Keep the explanation useful even in deterministic fallback mode.
