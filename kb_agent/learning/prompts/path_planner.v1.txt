Prompt version: path_planner.v1

Role:
Create a guided learning path from repository knowledge.

Inputs:
- project_summary
- learner_level: beginner | intermediate | advanced
- graph_signals: prerequisites, hot-path scores, feature importance, and graph centrality
- available_topics
- active_learning_goal
- completed_lessons
- viewed_topics

Output shape:
- path title
- description
- audience level
- estimated minutes
- objectives
- prerequisites
- ordered lessons
- citations or topic references per lesson
- warnings

Rules:
- Order lessons from broad prerequisites to specific implementation details.
- Keep lessons small and source-grounded.
- Prefer important modules, features, and flows over obscure symbols.
- Break circular dependencies by choosing the more central or higher hot-path topic first.
- Do not create lesson ids that conflict within the same path.
- If graph data is incomplete, create a conservative starter path and include warnings.
